# ZA Divergent local rate-limit test bundle

An isolated emulator-only candidate for a 10-second per-account chat posting interval, reciprocal message/activity validation, own-membership reads and message deletion permissions.

Run `npm install && npm test` inside this folder. Node 22 or newer, npm and a Java runtime compatible with the installed Firestore emulator are required. The test command uses only a local emulator and a `demo-` project ID, with no account login or billing setup. The host guard refuses remote test connections. A dependency lockfile is generated by installation.

This is not the complete chat ruleset and must not be deployed as-is. The moderator UID `emulator-moderator-only` is a fixture, not the owner's identity. Replace it with the verified owner UID before any approved deployment. No moderator write bypass is granted: moderation only permits message reads/removal. Membership provisioning remains a trusted console action. A suspended author may still delete their own messages.

Deleting a message never clears its activity record. Clients and moderators cannot delete activity, change membership, or edit messages. Rules deny everything not explicitly allowed, including profiles and reports not implemented in this slice. A separate approved account-deletion process will need owner-assisted cleanup without introducing a limiter reset bypass.

The 10-second interval is a recommendation. The 20-send races cover both missing and existing activity, and denied-batch checks verify rollback with no orphan messages or partial activity. Emulator results are local evidence, not production validation; no real Firebase project is configured or tested here. Real-project concurrency checks need separate approval and sign-in. Rate limits do not stop multi-account abuse, repeated bounded reads or quota exhaustion. Dependent rules reads consume quota; measure trial usage rather than equating each function call with a billed read.

Source design: the previously delivered rate-limit draft. Reference: https://firebase.google.com/docs/firestore/security/rules-conditions
